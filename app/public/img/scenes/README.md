# Stage scenes

Eight soft 3D clay illustrations, one per tracker stage (`open`, `asked`, `held`, `shopping`, `paid`,
`released`, `flying`, `delivered`). Generated for this project on 31 Oct 2026 with OpenAI image
generation through the Codex CLI (`codex exec`, image_generation feature), all from one style
reference (the `held` card + padlock) so the set matches. Resized to 900x600 WebP.

Shared prompt: soft 3D clay style, matte pastel materials, soft studio light from upper left, soft
contact shadow, single centred subject at ~45% width, plain flat background (the colour each scene
uses in `js/scenes.js`), no text or logos.
