# Images

All images here were generated for Jastip on 31 Oct 2026 with OpenAI image generation through the
Codex CLI (`codex exec`, image_generation feature), in one soft 3D clay style, then resized to WebP/PNG.

- `scenes/` – one illustration per tracker stage (see `scenes/README.md`).
- `avatars/a01..a16.webp` – 3D character avatars (192 px). A new user gets a random one; they can
  change it in the "You" sheet. Background colours are listed in `js/money.js` (`AVATARS`).
- `brand/` – app mark (`mark.webp`, `icon-192/512.png`, `apple-touch-icon.png`, `favicon-48.png`),
  `hero.webp` (welcome screen) and `og.jpg` (1200x630 link preview, laid out in HTML and rendered).
